## Surprises / lessons

1. **A PostgreSQL inside WSL owns port 5432 on this machine.** WSL2 and Docker Desktop
   share the VM network, so the WSL server shadows the container's published port and
   answers with "password authentication failed" for our user. Diagnosis: the container
   logged no FATAL entries for those attempts. Fix: host port 5433.
2. **`str(URL)` in SQLAlchemy 2.x masks the password as `***`.** Our fixture
   round-tripped the URL through `str()`, so psycopg literally authenticated with
   password `***` — producing the SAME symptom as (1) right after (1) was fixed, which
   made diagnosis genuinely confusing. Fix: `render_as_string(hide_password=False)`.
   Both traps recorded in CLAUDE.md for future sessions.
