# 0005 — 2026-08-05 — 0.5: CI workflow

## What was done

- `.github/workflows/ci.yml`: `quality` job on pushes to main and PRs — matrix over
  components (currently `libs/common`), Poetry pinned to 2.4.1 via pipx, Python 3.13,
  poetry cache keyed on each component's lock file, `ruff check` + `ruff format --check`
  + `pytest`.
- The integration job (pgvector service container, PRs only) is deliberately deferred to
  Phase 1, landing together with the first integration tests.

## Why

Quality gate from the first push; the matrix makes adding a component a one-line change
(mirrors the Makefile `COMPONENTS` list).

## How it was tested

YAML parses cleanly. The workflow itself can only run on GitHub — first real execution
will happen on the first push, which is pending Jeronimo's explicit go-ahead.
