# 0002 — 2026-08-05 — 0.2: Agent harness (CLAUDE.md + skills)

## What was done

- Project `CLAUDE.md` (local-only): critical policies (git authorship without AI
  attribution, docs privacy, secrets, cost gates, live verification), component map

- Eight skills under `.claude/skills/`:

  - `run-evals` — suite/mode selection, cost gate, report + regression comparison

  - `verify-vertex` — live model availability checks against `pokedex-rag-504617`

## Why

Future sessions must be able to cold-start from `CLAUDE.md` alone and produce uniform
docs and safe behavior (no accidental pushes of local-only content, no unestimated
spend, no unverified model names).

## How it was tested

Static review: skill frontmatter follows the `name`/`description` format Claude Code
loads; every referenced path exists. `git status` in the main repo confirms
`CLAUDE.md` and `.claude/` remain untracked. Behavioral verification will happen
naturally the first time each skill is invoked.
