  the client passes `pokedex-rag-504617` explicitly).

## Surprises / lessons

- Model garden LISTING ≠ regional serving availability: `gemini-embedding-2` shows up in
  us-central1's list but only serves from `global`. Listing alone is not verification.
- Google ships both normalized (gemini-embedding-2) and unnormalized
  (gemini-embedding-001 truncated) embedding behaviors — the defensive norm check in the
  future `GeminiEmbedder` is justified by live evidence, not paranoia.
